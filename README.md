# 🐼 Apache Kafka Python Handbook

A collection of simple, practical examples and explanations for learning Apache Kafka with Python from basics to real-world usage. Covers Kafka fundamentals, producers, consumers, topics, partitions, offsets, consumer groups, serialization, schema registry, Redpanda, ksqlDB, and stream processing.

Designed for beginners to intermediate developers with clear explanations and hands-on examples. Perfect for learning, practice, and building strong Kafka fundamentals step by step.

# 🚀 How to Use

1. Follow the topics in order (each topic builds on previous concepts)
2. Read the explanations carefully before running examples
3. Start Redpanda locally using Docker Compose
4. Run Kafka producer and consumer examples using Python
5. Observe message flow using Redpanda Console UI and kcat
6. Practice creating topics, partitions, and consumer groups
7. Experiment with ksqlDB streams, tables, and queries
8. Modify examples and build your own Kafka applications
